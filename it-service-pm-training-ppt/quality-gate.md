# V6 质量门禁清单

定稿前逐项勾选。未通过项回到对应 Phase 修复。

## A. 结构与叙事

- [ ] 开篇 P4–22 形成「定位→价值→生命周期→流水线→方法→能力」链条
- [ ] 每个大纲章节至少有 1 页概念页
- [ ] 关键框架（ITIL、PMBOK、PM 框架）有 ≥1 页图例
- [ ] 重复标题均为「概念+图例+案例」展开，非误复制
- [ ] 章节过渡页完整且未改版式

## B. 版式

- [ ] 标题：Microsoft YaHei 30pt
- [ ] 正文：17–24pt
- [ ] 插入页有蓝色分割线（`#006BA6`）
- [ ] Logo 右上角完整
- [ ] 定稿无外露「（插）」标题

## C. 内容与图例

- [ ] 标题与页面图例/正文语义一致（无错位页）
- [ ] 含图例页 ≥ 90
- [ ] 复合图页无元素重叠、无截断
- [ ] 案例页有明确「案例：」前缀或等效标识

## D. 备注

- [ ] 无空备注（封面/空白模板除外）
- [ ] ≥85% 页面备注 ≥200 字
- [ ] ≥80% 页面含 PREP 四段标签
- [ ] 插入页备注含「插入理由」（定稿可仅保留在备注，不在标题）

## E. 技术

- [ ] PowerPoint/WPS 打开无「无法读取部分内容」
- [ ] 文件大小无异常暴增
- [ ] 总页数 230–260（1 天课程）

## F. 讲师走查（人工）

- [ ] 每章能在规定时长内讲完（~1.5 分钟/页）
- [ ] 无连续 5 页以上纯文字无图
- [ ] Q&A 页有视觉元素（非纯文字）

## 量化验收命令

```bash
python scripts/verify_quality.py <定稿.pptx> --min-notes 200 --report quality_report.json
```

对比 Gold Standard：

```bash
python scripts/verify_quality.py <定稿.pptx> --gold <V6.pptx>
```
