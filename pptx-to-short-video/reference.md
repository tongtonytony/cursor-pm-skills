# PPT 转短视频播报技能 - 参考文档

## 一、故事线策划建议

### 推荐结构（12～18 页）

| 段落 | 页数 | 内容示例 | 配图建议 |
|------|------|----------|----------|
| 开场 | 1～2 | 主题引入、引发共鸣 | 封面图、场景图 |
| 核心概念 | 3～6 | 大模型、提示词、AI 工具 | 发展阶段图、架构图、对比图 |
| 方法框架 | 4～8 | TRACE、提示词结构、WBS | 流程图、框架图、思维导图 |
| 案例实操 | 2～4 | 商业论证、项目章程示例 | 示例截图、模板图 |
| 收尾 | 1～2 | 行动建议、金句、致谢 | 总结图、二维码 |

### 言之有物的图片类型

- **流程图**：大模型发展、项目生命周期、提示词设计流程
- **框架图**：TRACE、提示词结构、WBS 分解
- **对比图**：AI 前后对比、工具矩阵
- **阶段图**：能力演进、学习路径
- **示例图**：商业论证、项目章程、需求规格

### 需过滤的内容

- 签到表、课程加分规则表
- 纯表格（无图示）
- 过长列表（>10 条）
- 仅页码、仅数字
- 与主线无关的过渡页

## 二、解读文案规范（1～3 分钟/页）

- **字数**：约 150～450 字（1 分钟≈150 字）
- **结构**：开场句 + 2～3 个要点 + 过渡/金句
- **语气**：亲切、专业、有代入感
- **用途**：拷贝到剪映「文本朗读」或「配音」功能生成语音

示例：

```
大家好，欢迎来到本期短视频。这一页我们来看大模型的发展阶段。
从规则驱动到数据驱动，再到今天的涌现能力，大模型正在重塑我们的工作方式。
接下来，我们会看到如何把这种能力应用到项目管理中。让我们一起加油。
```

## 四、剪映使用流程

1. 将 `img_upload/` 中的 JPG 导入剪映素材库
2. 按页顺序拖入时间轴
3. 从 Markdown 注释中拷贝「解读」文案，使用剪映「文本」→「朗读」生成配音
4. 调整每页时长与转场，导出短视频
