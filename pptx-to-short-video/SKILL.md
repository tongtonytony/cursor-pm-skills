# PPT 转短视频播报技能

作为短视频内容策划与制作专家，将用户提供的**原始 PPT 文件**转化为**可直接播报的 Marp 格式 Markdown**，并输出可供剪映使用的图片素材。目标是：从 PPT 到短视频，一气呵成，让目标读者感到赏心悦目、宾至如归。

---

## 触发场景

- 用户提供原始 PPT 文件，希望快速生成短视频素材
- 提及「PPT 转短视频」「短视频素材」「剪映」「Marp 播报」「图片故事」
- 需要将培训/课程 PPT 提炼为可剪辑的短视频脚本与图库

---

## 核心要求（必须遵守）

| 要求 | 说明 |
|------|------|
| **R1** | 去掉不适合短视频的 PPT 内容；每页图片需言之有物（如大模型发展阶段、流程图、提示词框架等） |
| **R2** | 所有图片前后有关联，自成一个故事，可作为剪映短视频制作的连贯素材 |
| **R3** | 页数控制在 **20 页以内**，每页图片有意义且前后有逻辑关系 |
| **R4** | 每页解读内容 **1～3 分钟**，以 Markdown 注释形式存放，不显示在 Marp 页面上，可拷贝到剪映生成语音 |
| **R5** | Marp 每页：**仅标题 + 居中图片**，上边除标题外无其他内容 |
| **R6** | 全中文输出，语气专业、亲切、有代入感 |

## 前置：确认源文件

执行前**必须确认**用户已提供：

- **原始 PPT 文件**（.pptx）：工作区路径或用户指定的完整路径

若未提供，询问：「请提供原始 PPT 文件的完整路径，或将文件放入工作区。」

---

## 第一步：提取 PPT 内容与关键图片

运行提取脚本，将 PPT 转为可读文本与图片：

```bash
python .cursor/skills/pptx-to-short-video/scripts/extract_pptx.py <PPT完整路径> [输出目录]
```

输出目录可选，默认输出到技能目录；若指定为项目下的 `10-Marp_slides`，则便于与现有 Marp 工作流整合。

**输出**：
- `pptx_extracted.txt`：每页标题、要点、布局说明
- `img/`：从 PPT 中提取的图片（`slide_N_img_J.扩展名`）

**必须完整阅读** `pptx_extracted.txt`，识别：
- 适合短视频的「故事线」：开场→核心概念→方法/框架→案例→收尾
- 言之有物的图片：流程图、阶段图、框架图、对比图、案例截图
- 需过滤的内容：签到表、纯表格、过长列表、无关过渡页

---

## 第二步：策划故事线与页选（≤20 页）

基于提取结果，**人工策划**（或由 AI 辅助）一个 **≤20 页** 的故事线，确保：

1. **开场**（1～2 页）：主题引入、引发共鸣
2. **核心概念**（3～6 页）：大模型、提示词、AI 工具等关键概念，配流程图/阶段图
3. **方法/框架**（4～8 页）：TRACE、提示词结构、WBS、项目管理计划等，配框架图
4. **案例/实操**（2～4 页）：商业论证、项目章程等示例
5. **收尾**（1～2 页）：行动建议、金句、致谢

每页对应：
- **标题**：一句话概括本页主题（≤15 字为宜）
- **图片**：优先使用 PPT 中已有的流程图/框架图；若无，标注「需补充：关键词」，供后续从花瓣网、图虫网、百度图库等选图
- **解读**：1～3 分钟口播文案（约 150～450 字），供剪映配音

---

## 第三步：生成 Marp 播报文件

产出 `short-video-slides.md`，格式如下：

```markdown
---
marp: true
theme: short-video
paginate: false
size: 16:9
---

<!-- 第1页：开场 -->
# 欢迎来到 AI 赋能项目管理的世界

![第1页](img_upload/slide_01.png)

<!--
解读（1～3分钟，可拷贝到剪映生成语音）：
大家好，欢迎收看本期短视频。今天我们将一起探索，如何用 AI 赋能项目管理，让工作更高效、更智能……
（约 150～450 字）
-->

---

<!-- 第2页 -->
# 大模型：从规则到涌现

![第2页](img_upload/slide_02.png)

<!--
解读（1～3分钟）：
大模型的发展经历了从规则驱动到数据驱动的跨越……
-->
```

**格式要点**：
- 每页仅 `# 标题` + `![描述](img_upload/slide_N.png)`
- 解读全部放在 `<!-- ... -->` 注释中，不显示在 Marp 页面
- 图片路径统一为 `img_upload/slide_N.png`（或 .jpg）

---

## 第四步：图片准备与导出

### 4.1 图片目录 `img_upload/`

- 将选定的图片放入 `img_upload/`，命名为 `slide_01.png`、`slide_02.jpg` 等
- 图片来源：PPT 提取的 `img/` 中挑选，或从 **花瓣网、图虫网、百度图库** 等下载补充
- 建议尺寸：1920×1080 或 16:9 比例，便于剪映使用

### 4.2 导出 JPG 供剪映上传

使用 Marp 扩展「Export slide deck」导出为 **PNG/JPEG**，或运行：

```bash
python .cursor/skills/pptx-to-short-video/scripts/export_marp_to_jpg.py
```

将导出的图片保存到 `img_upload/`，可直接上传至剪映素材库。

---

## 第五步：Marp 主题（仅标题 + 居中图片）

本技能提供 `themes/short-video.css`，确保：
- 标题居中、字号适中
- 图片居中、占满可用区域，上下除标题外无其他内容
- 背景简洁，适合短视频观感

在 `short-video-slides.md` 的 YAML 头中设置 `theme: short-video`，并在工作区 `.vscode/settings.json` 中注册：

```json
{
  "markdown.marp.themes": [".cursor/skills/pptx-to-short-video/themes/short-video.css"]
}
```

## 注意事项

1. **不臆造内容**：若 PPT 中无合适图片，在解读中说明「建议配图：关键词」，由用户自行到花瓣网、图虫网等选图补充
2. **故事优先**：宁可少而精，不可多而杂；20 页是上限，建议 12～18 页为佳
3. **解读可编辑**：注释中的解读文案可根据实际口播习惯调整，拷贝到剪映时注意分段与停顿
4. **全中文**：标题、解读、注释均使用中文，语气亲切、专业、有代入感
