# AI赋能项目经理培训PPT生成技能（升级版 V2.0）

作为国内首屈一指的AI专家、项目管理专家与PPT制作专家，根据《AI赋能项目经理实现卓越项目管理培训大纲》和《待裁剪PPT资源》，通过**三步流程**（提取→规格设计→生成/修订）产出与大纲章节完全一致、内容专业、格式统一的培训PPT。

## 触发场景

- 制作「AI赋能项目经理」培训PPT/课件
- 基于培训大纲设计PPT
- 从待裁剪PPT资源中选取并修订内容生成培训课件
- 提及「AI赋能项目经理」「培训PPT」「培训大纲」「待裁剪PPT」

## 前置：确认源文件与可选配置

执行本技能前，**必须先确认**以下文件在工作区或用户可访问路径下：

| 文件 | 用途 |
|------|------|
| `AI赋能项目经理实现卓越项目管理培训大纲.docx` | 大纲结构、章节对应、内容逻辑 |
| `待裁剪PPT资源.pptx` | 排版格式、风格、可复用内容、章节过渡方式 |

**可选配置**（用于定制化输出）：
- 讲师信息（姓名、简介、出版书籍、公众号）
- 客户/培训对象（如佛山电信、XX电信）
- 资料共享链接（百度网盘等）
- 课程加分规则、学习路径说明
- 演讲时长（默认3小时，约1.5分钟/页）

若用户未提供路径，询问：「请提供《AI赋能项目经理实现卓越项目管理培训大纲.docx》和《待裁剪PPT资源.pptx》的完整路径，或将文件放入工作区。」

## 第一步：提取源文件内容

运行提取脚本，将大纲与PPT内容转为可读文本，供大模型长文本阅读与分析：

```bash
cd .cursor/skills/ai-pm-training-ppt
python scripts/extract_source_content.py <大纲docx完整路径> <待裁剪PPT完整路径>
```

或从工作区根目录：

```bash
python .cursor/skills/ai-pm-training-ppt/scripts/extract_source_content.py <大纲路径> <PPT路径>
```

**输出**：
- `outline_extracted.txt`：大纲章节结构与要点
- `pptx_extracted.txt`：PPT每页文本、布局与风格说明

**必须完整阅读**以上两个文件，不遗漏任何可适配培训PPT的细节。利用大模型长文本能力，对待裁剪PPT进行全文扫描，识别与以下关键词相关的页码：商业论证、项目章程、需求规格、概要设计、WBS、进度网络图、项目管理计划、风险管理、干系人、Dify、Coze、Mermaid、TRACE、提示词。

   - 客户/培训对象名称（如佛山电信）
   - 是否需要讲师介绍、课程加分规则、公众号、资料共享链接？
   - 若有，请用户提供具体内容或确认使用默认模板

## 第三步：生成 PPT 内容规格（强制步骤）

**在运行任何 PPT 生成脚本之前**，必须先产出 `PPT内容规格_XXX.md`，作为可追溯、可修订的中间产物。

### 规格文档要求

1. **与大纲完全一致**：每个大纲章节必须有对应PPT页，且顺序一致
2. **必含交付物清单**（大纲明确要求的）：
   - 商业论证自动生成
   - 项目章程自动生成
   - 项目需求规格说明书
   - 项目概要设计说明书
   - 项目工作分解结构（WBS）
   - 项目进度网络图
   - 项目管理计划
   - Dify 工作流实现项目绩效实时监控
   - 项目经验教训知识库
3. **每页规格格式**：
   - 页码
   - 标题
   - 要点（3～7条）
   - 对应大纲章节
   - 待裁剪PPT页码（若可复用）
4. **内容优先从待裁剪PPT选取**：能复用的尽量保留并标注来源页码，不足处补充说明
5. **章节过渡**：参考待裁剪PPT的呈现方式，每章包含「概况/过渡页」

### 规格文档结构参考

```

## 第一部分：开场与课程概览（第1-N页）
### 第1页：封面
### 第2页：讲师介绍（若需）
...

## 第二部分：模块一 · 提示词工程与特定AI工具
...

## 第三部分：模块二 · AI在项目全生命周期的应用
### 项目启动：商业论证、项目章程、风险识别、干系人
### 项目规划：需求分析、设计文档、WBS、进度网络图、风险管理
### 执行与监控：周报/会议纪要、进度/成本偏差预警
### 项目收尾：交付物清单、经验教训知识库
...

## 第四部分：模块三 · 未来趋势与组织应对
...

## 附录：页数统计与大纲对应表
```

**输出规格后**：请用户确认或修订，再进入第四步。

## 第四步：PPT 设计原则

### 内容重点（与大纲完全一致）

**模块一**：提示词工程与AI工具
- 提示词技巧（直接提问、少样本、分配角色、TRACE框架等）
- 项目管理计划自动生成、Mermaid/PlantUML/Coze/Dify/Cursor
- 智能体与工作流
- 需求规格说明书、架构设计文档自动化研讨

**模块二**：项目全生命周期
- **项目启动**：商业价值分析、商业论证、项目章程、风险识别、干系人识别、政企实操
- **项目规划**：需求分析文档、设计文档、概要设计、WBS智能分解、进度估算与关键路径、进度网络图、项目管理计划、风险管理计划
- **执行与监控**：周报/会议纪要（语音转写+摘要）、进度/成本偏差预警
- **项目收尾**：交付物清单、经验教训知识库

**模块三**：AI驱动的项目管理未来趋势与组织应对
- 趋势1：多个AI智能体的协同
- 趋势2：本地知识库+通用大模型
- 趋势3：PM角色进化
- 组织建议、互动问答

### 内容选取与修订

- **优先从《待裁剪PPT资源》选取**：能复用的尽量保留，必要时做修订、扩展
- **章节逻辑与大纲一致**：第 X 章 PPT 内容必须对应大纲第 X 章
- **章节过渡**：参考待裁剪PPT的呈现方式，做「第 X 章概况」类过渡页
- **充分利用长文本能力**：不遗漏待裁剪PPT中任何可适配细节
- **必含交付物**：商业论证、项目章程、需求规格、概要设计、WBS、进度网络图、项目管理计划、Dify工作流与经验教训知识库——若待裁剪PPT中无对应页，需在规格中明确「需补充」并在生成时创建

### 格式与风格

- 排版、配色、版式尽量与《待裁剪PPT资源》一致
- 模板格式与待裁剪PPT保持一致
- 允许英文缩写（如 WBS、PRD、Dify、RAG），全文以中文为主
- 避免错别字、乱码

## 第五步：生成/修订 PPT

### 方式A：纯删除策略（推荐，避免 rId 损坏）

1. 根据 `PPT内容规格.md` 和 `outline_slide_map.json`（或脚本内映射），确定要保留的待裁剪PPT页码
2. 运行修订脚本：
   ```bash
   cd .cursor/skills/ai-pm-training-ppt/scripts
   pip install -r requirements.txt
   python revise_training_ppt.py
   ```
3. 修订脚本采用**纯删除策略**：从待裁剪PPT中保留所需页并删除其余页，绝不跨文件复制幻灯片

### 方式B：内容规格驱动（需扩展脚本）

若规格中有「需补充」页而待裁剪PPT无对应内容：
- 可运行 `create_pptx_from_spec.py` 生成新页，再手工合并
- 或先在待裁剪PPT中插入空白占位页并标注，再运行删除策略

### 页映射配置

- 默认使用 `revise_training_ppt.py` 中的 `OUTLINE_SLIDE_MAP`
- **若待裁剪PPT结构变化**：请将映射外置为 `outline_slide_map.json` 或修改脚本中的映射表
- 映射格式：`(章节名, [待裁剪PPT页码列表 0-based])`

## PPT 打开报错修复

若生成的PPT在 PowerPoint/WPS 中打开时提示「无法读取部分内容」或「文件已损坏」：

- **成因**：跨文件复制幻灯片时 relationship ID（rId）引用断裂
- **对策**：修订脚本采用**纯删除策略**：
  1. 以「待裁剪PPT资源.pptx」为唯一来源，复制整文件后再删除不需页
  2. 绝不跨文件复制幻灯片，从根本上避免 rId 损坏
  3. 删除前调用 `drop_rel` 释放关联，从后向前删除避免索引错位
