# AI赋能项目经理培训PPT Agent Skills —— 升级版提示词

> 供 Cursor Agent Skills 设计参考，确保基于大纲和待裁剪PPT生成靠谱、内容丰富、格式统一的培训PPT。

---

## 一、核心角色设定

作为国内首屈一指的**AI专家**、**项目管理专家**和**PPT制作大师**，请帮我设计/升级一款可支持「基于课程大纲和待裁剪PPT资源生成AI赋能项目经理培训PPT」的 Agent Skill。

---

## 二、Skill 创建要求

### 要求1：文件与路径

- 创建 SKILL 对应的 MD 文件，放到 Cursor 关联的 `.cursor/skills/ai-pm-training-ppt/` 路径下
- 包含 name、description、触发场景、执行步骤、参考文件

### 要求2：PPT 内容重点

PPT 需重点突出：

- **AI 基本概念**：大模型、提示词工程、RAG、智能体与工作流
- **项目管理应用**：
  - 自动生成商业论证
  - 自动生成项目章程
  - 自动生成项目需求规格说明书
  - 自动生成项目概要设计说明书
  - 自动生成项目工作分解结构（WBS）
  - 自动生成项目进度网络图
  - 自动生成项目管理计划
  - 基于 Dify 工作流实现项目绩效实时监控
  - 项目经验教训知识库自动生成与归档

### 要求3：内容选取与逻辑

- **内容优先从《待裁剪PPT资源》选取**，能复用的尽量保留并做必要修订、扩展
- 修订后生成的 PPT 内容及前后逻辑**必须与《培训大纲》对应章节一致**
- 不遗漏待裁剪PPT中任何可适配的细节（充分利用大模型长文本能力）

### 要求4：互动确认

以互动方式询问：

- 本次培训的**演讲时长**（默认 3 小时）
- 按约 1～2 分钟/页估算页数
- 是否需要**定制参数**：讲师信息、客户名称（如佛山电信）、资料共享链接、课程加分规则

### 要求5：格式与风格

- 排版格式与《待裁剪PPT资源》保持一致
- 若内容可复用，尽量保留原始 PPT 内容并做必要扩展
- 章节过渡（如第 X 章概况）参考待裁剪PPT的呈现方式

### 要求6：专业输出

- 立足待裁剪PPT相关内容，做到专业输出
- 全文以中文为主，可有英文缩写（如 WBS、PRD、Dify）
- **不得有错别字和乱码**

### 要求7：大纲与目录完全一致

- PPT 目录结构必须与《培训大纲》的模块内容**完全一致**
- 必须包含：商业论证、项目章程、需求规格说明书、概要设计、WBS、进度网络图、项目管理计划等相关理论和实验环节
- 尽量引用并填充来自《待裁剪PPT资源》的内容

### 要求8：强制三步流程

1. **提取**：运行 `extract_source_content.py`，产出 `outline_extracted.txt` 和 `pptx_extracted.txt`
2. **规格设计**：根据大纲和待裁剪PPT，产出 `PPT内容规格_XXX.md`，作为可追溯的中间产物
3. **生成/修订**：根据规格执行 `revise_training_ppt.py` 或等效脚本，产出最终 PPT

### 要求9：避免 PPT 打开报错

- 采用**纯删除策略**：从待裁剪PPT保留所需页并删除其余页
- **绝不跨文件复制幻灯片**，避免 rId 引用断裂导致「PowerPoint 无法读取部分内容」

### 要求10：持续改进

- 参考用户手工修订版本（如 V1.0）与 Agent 生成版本（如 V0.1）的差异
- 将「短板原因」与「改进建议」纳入 Skill 文档或独立分析文档，供后续迭代
