# 商业论证生成技能

基于「AI赋能项目管理：特定行业/项目商业论证格式/内容生成」的方法论，支持为任意行业、任意项目生成规范的商业论证文档。

## 触发场景

当用户表达以下意图时应用本技能：
- 需要生成/编写商业论证
- 项目立项论证、投资可行性论证
- 提及「商业论证」「Business Case」
- 需要基于模板填充商业论证内容

## 工作流程

### 第一步：互动式信息收集

在生成商业论证之前，**必须先以对话方式收集**以下必要信息。若用户未一次性提供，则逐项询问：

#### 必填信息

| 信息项 | 说明 | 示例 |
|--------|------|------|
| **行业** | 项目所属行业/领域 | 政务信息化、金融、能源、医疗、制造业、教育等 |
| **项目名称** | 项目的正式名称 | 某市局单位IDC容灾备份咨询与落地实施项目 |
| **项目发起组织** | 编制单位/部门 | 某市局信息化管理处 |

#### 建议收集的扩展信息

| 信息项 | 说明 | 是否必填 |
|--------|------|----------|
| 项目背景与目标 | 项目的核心目标、要解决的问题 | 建议必填 |
| 政策/监管依据 | 相关法规、行业标准、上级要求 | 按行业而定 |
| 实施周期 | 预计总周期及各阶段时长 | 建议必填 |
| 预算范围 | 一次性投入与年度运维成本区间 | 建议必填 |
| 主要风险 | 已知的进度、技术、组织等风险 | 可选 |
| 可选方案对比 | 「做」「少做」「不做」的对比说明 | 可选 |
| 预期收益类型 | 社会效益、管理效益、经济收益等 | 建议必填 |

#### 一次性录入表单

若用户希望一次性提供全部信息，可引导其按以下格式填写（支持复制粘贴或逐条回答）：

```
【商业论证信息录入单】

一、基础信息
- 行业：
- 项目名称：
- 项目发起组织/编制单位：

二、项目概要
- 项目核心目标（1-3句）：
- 关键交付物概述：

三、实施理由
- 政策/监管要求（如有）：
- 业务痛点或历史事故（如有）：
- 「不做」的风险简述：

四、可选方案（可选）
- 推荐方案简述：
- 其它方案及对比：

五、预期收益
- 社会效益/管理效益/经济收益：
- 预期负收益及占比说明：

六、实施安排
- 总周期：
- 阶段划分及关键交付物（可列表）：

七、成本估算
- 一次性投入（金额或区间）：
- 年度运维成本（如有）：

八、可行性简述
- 技术/经济/管理/合规可行性要点：

九、主要风险与应对
- 风险1及应对：
- 风险2及应对：
（可扩展）

十、结论
- 建议结论（如：强烈建议批准立项）：
```

### 第二步：确定输出格式

1. **用户提供自定义 Word 格式**：若用户上传或指定了公司/客户的 Word 模板（.docx），则严格按照该模板的章节结构、样式、标题层级输出。
2. **默认格式**：若用户未提供自定义格式，则按照「商业论证交付样例」的结构和层级输出。完整结构见 [reference.md](reference.md)。

### 第三步：生成商业论证

1. 依据收集到的信息，按选定格式填充各章节内容。
2. 确保内容符合 CSPM/GB_T 37507 中商业论证的要素：目标、收益、成本、风险、可行性（技术/商业）。
3. 行业术语、政策引用、数字单位等应与用户所述行业一致，避免泛泛而谈。
4. 若信息不足，对缺失章节标注「[待补充：XXX]」，并提示用户后续补充。

### 第四步：输出与修订

1. 输出格式：优先生成 `.docx` 文件；若不支持直接生成 Word，则输出结构完整、标题层级清晰的 Markdown，便于用户复制到 Word。
2. 中文表述：全文使用中文，避免错别字、乱码；数字、单位、日期格式符合中文习惯（如：2026年2月4日、万元、%）。
3. 若用户需调整某章节，根据反馈单独修订该部分并保持整体一致。

## 商业论证核心结构（默认）

默认采用「商业论证交付样例」的九部分结构：

1. 内容概要  
2. 实施理由或原因  
3. 可选商业方案表格  
4. 预期收益  
5. 预期负收益  
6. 实施周期表格  
7. 实施成本表格  
8. 可行性评估表格  
9. 主要风险表格  
10. 结论  
11. 编制单位与日期  

详细字段说明与示例见 [reference.md](reference.md)。

## 注意事项

1. **不臆造**：未收集到的政策条文、具体金额、事故案例等，不得编造，应标注待补充或使用占位符（如 XX万元、XX日）。
2. **行业适配**：政务类强调政策合规、审计整改；企业类可侧重 ROI、市场竞争；医疗/金融需体现行业监管要求。
3. **逻辑闭环**：实施理由 → 可选方案 → 收益/成本/风险 → 结论，保持逻辑连贯。
4. **格式规范**：标题层级清晰（一级、二级、三级），表格结构完整，便于在 Word 中进一步排版。
